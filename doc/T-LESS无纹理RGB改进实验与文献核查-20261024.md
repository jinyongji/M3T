## 2. 从已有结果提出问题

当前RGB静态视点环主结果：Ours 48.5464%，ICG+47.8290%，SRT3D49.5728%，ICG49.2827%。Ours的CAD-DISK未参与，差距尤其集中在10%—50%可见度：Ours13.6838%，SRT3D29.1033%。这些是已有结果，不是改进后分数。

因此第一版实验检查两类可解释原因：视频ORB中不一致的2D–3D对应是否损害弱纹理/遮挡输入；颜色直方图是否在遮挡时被污染。尚不能从汇总断定它们就是根因。只针对数据集改阈值或修改评测分母不能回答这些问题。

本轮不强行开启CAD-DISK：CAD仍无贴图，几何模型不能自动提供与真实RGB相符的纹理。新PnP验证利用已有视频关键帧与当前帧之间、由CAD几何关联的3D点；它不需要CAD外观贴图，也不输入传感器深度。

## 3. 用户文献材料的核查与可借鉴范围

用户提供了《TLESS_位姿估计与物体跟踪文献整理.md》，其中26类位姿方法不等于26类连续跟踪方法。本次重点复核以下官方来源，其他较新条目及其精确分数没有逐一重新核实，不直接作为统一对比表。

| 参考 | 已核对的内容 | 对当前RGB代码的启发与边界 |
|---|---|---|
| PoseRBPF | 旋转/平移分布递推，处理对称性；另有RGB-D扩展 | 后续可研究对称等价姿态与多假设；本次PnP门控不是PoseRBPF复现 |
| TP-AE | 历史运动预测与RGB-D观测融合，面向对称、无纹理、遮挡 | 可借鉴按观测置信度调整预测；其RGB-D成绩不是本轮RGB可直接对照的分数 |
| DeepAC | 学习的活动轮廓跟踪；官方列T-LESS用于训练/验证，跟踪测试为RBOT、BCOT、OPT | 支持从轮廓与观测可靠性思考弱纹理问题；本次启用的既有颜色共识不是DeepAC实现 |

官方来源：[PoseRBPF扩展版论文](https://yuxng.github.io/Papers/2021/deng_tro21.pdf)、[官方仓库](https://github.com/NVlabs/PoseRBPF)；[TP-AE论文](https://lynne-zheng-linfang.github.io/TP-AE.github.io/resources/TP-AE.pdf)、[项目页](https://lynne-zheng-linfang.github.io/TP-AE.github.io/)；[DeepAC官方说明](https://github.com/WangLongZJU/DeepAC)。

TP-AE官方仓库README在本次核查时仍标注未完成，不能把它当作开箱即可公平复现的比较包。[官方仓库](https://github.com/Lynne-Zheng-Linfang/TP-AE_Object_tracking)

文献中的单帧定位、精修、多视角AR、固定VSD阈值召回和当前MSSD/d≤0.1视点环成功率，任务与协议不同。数值不可直接混排；若后续加入新对比方法，要在相同RGB、帧序、初始化和重置协议下实际复测，并保留训练条件。

## 4. 已实现的第一版实验

| ID | 视频PnP验证 | RGB可见性共识 | 视频约束 | 目的 |
|---|---:|---:|---|---|
| B0 | 关 | 关 | 原样 | 与冻结Ours逐帧回归的基底 |
| B1 | 开 | 关 | 只保留几何验证内点 | 检查不一致ORB匹配 |
| B2 | 关 | 开 | 原样 | 检查轮廓权重及颜色模型更新 |
| B3 | 开 | 开 | 几何验证内点 | 预先固定的组合候选 |
| B4 | 关 | 关 | 清空 | Region约束对照，保留纹理维护 |

### 4.1 视频几何一致性

视频关键帧已有的模型3D点与当前ORB像素进入PnP-RANSAC。固定100次迭代、4px重投影阈值、0.99置信度，至少6个内点且不少于候选点一半。再次验证正深度及4px重投影误差；点集非有限、退化、支持不足或求解失败时，本帧不给视频项加入错误约束，仍由Region及既有运动模块跟踪。

RANSAC估计仅用于筛选对应，不直接覆盖跟踪位姿。只在每帧首次对应迭代做验证；全部开销计入计算时间。颜色、模型3D对应、内参是输入，不使用评分GT、标注可见度或成功标签作选择。

这是一个可能有效也可能过度拒绝正确特征的候选机制，必须同时报告拒绝比例、计算成本和失败变化。不是给CAD-DISK补了纹理，也不代表DISK已经执行。

### 4.2 既有RGB可见性共识

启用冻结代码中已有、默认关闭的 `use_visibility_consensus` 和 `visibility_local_memory` 开关，按前后景颜色证据为轮廓线降权、筛选颜色直方图更新。证据来自图像和因果历史，不使用GT可见度。该实现已存在于旧代码，本次只是独立启用并评价，不能包装成新实现的完整算法贡献。

这不等于显式分割，也不能保证准确识别遮挡。低对比度工件可能被误判，直方图更新也可能因筛选不足而停滞，B2对照用于检查这些风险。

### 4.3 源码隔离

`examples/tless_rgb/` 生成独立驱动和一个只增加内联访问器的纹理头文件覆盖层，不改冻结M3T实现、不改原五方法入口。派生纹理模态只在对应变体启用过滤；B0保留原计算路径。运行时开关、候选/保留匹配数、验证标记、颜色证据和激活量逐帧保存，且在GT重置前捕获。

B4仍建立并维护纹理模块，只清空其视频约束，因此可以观察视频项对准确率的影响，不能把B4耗时当作最快纯Region实现。

## 5. 协议和实验阶段

原始966个目标环、原图及归一化、首帧GT初始化、每环71评价视点、所有可见度、MSSD/d≤0.1和先计失败再GT重置均保留。每配置前10个评价帧只从计时剔除；不改传感器模态，不增加其他物体GT或已知相机运动输入。

| 阶段 | 配置 | 变体 | 每作业评价视点 | 主作业数 |
|---|---:|---|---:|---:|
| smoke | 原小测的三个目标环 | B0—B4 | 20 | 15，另3个旧Ours参照 |
| pilot | scene_01—05、15°/45°/75°，全部实例 | B0—B4 | 71 | 315 |
| full | 全部966目标环 | B0、B3 | 71 | 1,932 |

pilot规则在新结果前固定，不按旧成功率或GT可见度选“好帧”。Full候选固定为B3，避免从全量结果反选最有利开关。若pilot显示无增益，应保留负结果并重新分析，不必盲目做全量。

我们已经看过完整T-LESS成绩，因此新方法选择属于测试集上的探索性适配；即使另列部分场景，也不能追称为从未查看的独立测试集。投稿时应披露开发过程，并用新的D455真实运动/下游数据检验泛化。

## 7. 先小测，再pilot

以下命令沿用物理3号卡，可把末尾3换为当前可用卡；同一轮smoke与后续阶段要求相同GPU和运行环境。每行分别复制：

```bash
bash /home/jyj/Projects/tless-rgb-experiment/run_rgb.sh smoke 3
```

```bash
bash /home/jyj/Projects/tless-rgb-experiment/run_rgb.sh status
```

小测另运行冻结旧Ours，比较B0的预重置位姿、成功/重置标记和段号；沿用旋转矩阵元素差≤1e-4、平移差≤5e-5m。必须3项回归全部通过、manifest状态complete和 `regression_gate.json` 的passed=true，才能继续：

```bash
bash /home/jyj/Projects/tless-rgb-experiment/run_rgb.sh pilot 3
```

运行均为nohup后台任务。先把pilot的 `summary.json`、`results.md` 和小测 `regression.json`用于分析，再决定是否运行已经实现的B0/B3全量入口：

```bash
bash /home/jyj/Projects/tless-rgb-experiment/run_rgb.sh full 3
```

full只检查严格小测通行，不自动宣称B3准确率更好；不能因为脚本允许full就跳过pilot分析。若B0回归不通过，保存首次差异，不放宽容差。
